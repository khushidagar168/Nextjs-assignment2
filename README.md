# Next.js Dashboard Assignment

A professional, responsive dashboard built with Next.js, Shadcn UI, and Tailwind CSS.

## Features

- **Responsive Sidebar**: Collapsible navigation with support for desktop and mobile views.
- **Metric Cards**: Real-time summary of key performance indicators (Revenue, Users, Sales, Active Now).
- **Interactive Charts**: Data visualization using Recharts for monthly revenue trends.
- **Recent Transactions**: Detailed list of recent sales with customer information.
- **Dark Mode**: Integrated theme toggling for light and dark environments.
- **Interactivity**: Dynamic tabs, date range selection, and toast notifications.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI (Radix UI)
- **Icons**: Lucide React
- **Charts**: Recharts
- **Theming**: Next Themes

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

## Project Structure

- `src/app`: Application routes and layout.
- `src/components`: UI components, including the custom dashboard elements.
- `src/components/ui`: Shadcn UI primitive components.
- `src/lib`: Utility functions and shared logic.
